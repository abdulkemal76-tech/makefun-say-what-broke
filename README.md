Entry for the make.fun bounty [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5): one line of software error copy that tells the user the brutal truth about the failure and makes them laugh.

## Run

```sh
python3 -P -s main.py
```

Writes the entry line to `/output/entry.txt`.

## The line

> The Save button saved nothing. Your file is exactly where you left it, unsaved, because the disk filled up at 11:47 p.m. Free some space, then save again.
